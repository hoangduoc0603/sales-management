## Quy tắc sử dụng registry

- Chỉ implement UI từ artifact có trạng thái `Approved`.
- Nếu artifact trên Open Design đã đổi nhưng registry chưa cập nhật, dừng lại và yêu cầu cập nhật handoff trước khi code.
- Nếu task yêu cầu màn hình chưa có trong registry, tạo hoặc cập nhật design/handoff trước khi implement UI.
- Khi đổi tên artifact, đổi project, đổi trạng thái duyệt hoặc đổi đường dẫn file Open Design, cập nhật registry trong cùng thay đổi.
- Đường dẫn file chỉ dùng để mở nhanh trên máy hiện tại. Việc đổi vị trí lưu local không làm thay đổi source of truth; `Open Design project` + `Artifact chính` vẫn là định danh chuẩn.
- Trước khi code, dùng `Open Design project` + `Artifact chính` để lấy artifact hiện hành qua Open Design; sau đó mở đường dẫn file Open Design để đối chiếu trực quan. Không code UI chỉ từ screenshot.
- Nếu file local không tồn tại hoặc không mở được, dùng định danh chuẩn để lấy lại artifact qua Open Design; không coi file thiếu là design bị mất.
